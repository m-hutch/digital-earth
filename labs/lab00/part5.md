# Submit your lab report

1. Use the checklist at the top of the report document to double check that you completed all required items. **Type your initials next to each item that you successfully completed**. If there were any items you were unable to complete, do not write your initials next to that item.

2. Save and close your lab report document.

3. In the Digital Earth Canvas course, navigate to `Assignments`  then click the `Lab 0: Scavenger Hunt` assignment.

4. Under "**Choose a submission type**" make sure the `Upload` tile is selected.

5. Click "Choose a file to upload" then navigate to your `lab00` folder and select your **completed** `Lab_0_Report.docx` file. Click **Open**.

   <span class='alert'>You will only be able to upload the allowed file types (`.docx` or `.pdf` extensions). If your report is not in one of these types, you probably did not edit it in Microsoft Word as instructed. Try re-downloading the report template and opening it in the correct software before proceeding, then re-enter your lab report information using Microsoft Word.</span>

7. Click **Submit Assignment** to submit the assignment.

8. If the submission is successful you should see a confirmation banner at the top of the page and you will receive a confirmation email. **If you did not receive a confirmation email, the assignment did not submit successfully**

    <span class='tip'>Always save your confirmation emails for your records until final grades are posted at the end of the semester. </span>

9. If you made any mistakes in the submission, you can always re-submit for no penalty until the assignment deadline. **Only the last submission is graded**. If you upload half the report in one submission, and the other half in a second submission, only half the report will get graded! Make sure your last submission is the full assignment you want graded.
