# Lab 5 - 3D Modeling
*Estimated time to complete: 1 hour*

## Goals  
* Use intermediate level tools in QGIS
* Download elevation data and satellite imagery using QGIS
* Create a hillshade layer
* Model terrain in 3D
* Create a custom postcard layout
* _Bonus_: Create a Heat map from GPS data

## Key Performance Indicators
* **KPI 1**: Capture a satellite image of a location
* **KPI 2**: Represent Terrain using a Digital Elevation Model (DEM)
* **KPI 3**: Represent a DEM as a hillshade image
* **KPI 4**: Create a 3D Model of a DEM
* **KPI 5**: Create a postcard layout

## Requirements  
* QGIS
* Microsoft Word
* An email account

## Optional  
* A computer mouse (separate from a laptop track-pad) for easy map navigation

## Lab Overview

There are **nine** sections to this lab:
- How to get an OpenTopographyAPI Key
- Install Required Packages
- How to capture a Satellite Image 
- How to download a Digital Elevation Model (DEM)
- How to create a Hillshade from a DEM
- How to Make a 3D View in QGIS
- How to make a postcard layout
- Bonus: How to make a Heatmap from GPS Data
- Submit your lab report

Please complete each part in order and submit your lab report before the due date.
